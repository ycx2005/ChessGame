# Chess Game Project

## About
This is a personal project developed to explore game tree algorithms and search optimization. The primary objective is to create an engine capable of beating an intermediate player (~1500+ Elo).

## Planned features
- **Full Chess Ruleset**: Castling, _en passant_, pawn promotion and 50 move draw.
- **Evaluation Function**: Material weighting, piece-square tables and center control heuristics.
- **Search Algorithm:** Minimax with Alpha-Beta pruning.

## Tech Stack
- **Language** [C++20]
- **Dependencies** [Standard Library only]
